# Скрипт отправки файлов в Apache ActiveMQ Artemis (AMQP 1.0)

Скрипт на Python для отправки бинарных файлов с пользовательскими заголовками в очереди Artemis. Работает по защищенному протоколу **AMQP 1.0 (SSL/TLS)** с автоматическим игнорированием самоподписанных сертификатов.

## 0. Получение утилиты из GitHub

Перед началом настройки склонируйте репозиторий с проектом на вашу локальную машину или целевой сервер. Откройте терминал и выберите один из удобных способов:

### Вариант А. По протоколу HTTPS (Рекомендуемый для быстрой настройки)
```bash
git clone https://github.com/
cd amqp_send
```

### Вариант Б. По протоколу SSH (Если настроены SSH-ключи в GitHub)
```bash
git clone git@github.com:ваш_аккаунт/amqp_send.git
cd amqp_send
```

*После перехода в папку проекта `cd amqp_send` можно приступать к установке системных зависимостей, описанной в следующем шаге.*

## 1. Установка системных зависимостей

Поскольку библиотека `python-qpid-proton` компилирует свое C-ядро при установке, в системе должны быть установлены компилятор и заголовочные файлы Python. Откройте терминал и выполните команду для вашей ОС:

### WSL (Ubuntu) / Astra Linux (Орел/Воронеж/Смоленск)
```bash
sudo apt update
sudo apt install -y build-essential python3-dev python3-venv python3-pip
```

### РЕД ОС (7.3 / 8.0)
```bash
sudo dnf check-update
sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y python3-devel
```

---

## 2. Развертывание виртуального окружения (Python venv)

Перейдите в директорию с вашим скриптом и выполните команды для изоляции зависимостей проекта:

```bash
# 1. Создаем виртуальное окружение с именем .venv
python3 -m venv .venv

# 2. Активируем его
source ./.venv/bin/activate

# После активации в начале строки терминала появится префикс (.venv)
```

---

## 3. Установка модулей Python

Обновите менеджер пакетов `pip` и установите зависимости из файла `requirements.txt` одной командой:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
*Сборка и установка пакета `python-qpid-proton` займет около 10–20 секунд.*

---

## 4. Конфигурация и запуск

1. Откройте файл `amqp_send.py` и настройте параметры в блоке `КОНФИГУРАЦИЯ СКРИПТА` (URL брокера в формате `amqps://`, имя очереди, путь к файлу и кастомные заголовки).
2. Запустите скрипт, передав пароль от учетной записи брокера через переменную окружения:

```bash
USER_PASSWORD="ваш_пароль_от_artemis" python amqp_send.py
```

## Деактивация окружения
Выйти из виртуального окружения по окончании работы можно командой:
```bash
deactivate
```
## 4. Инструкция по использованию

### Шаг 1. Настройка параметров скрипта

Откройте файл `amqp_send.py` в текстовом редакторе и настройте переменные в секции `КОНФИГУРАЦИЯ СКРИПТА` под вашу задачу:

```python
# ==================== КОНФИГУРАЦИЯ СКРИПТА ====================
BROKER_URL = "amqps://10.3.124.31:61627" # Адрес брокера (обязательно amqps:// для SSL)
QUEUE_NAME = "TO.KM"                      # Имя целевой очереди (Address в Artemis)
USER_NAME = "main"                        # Имя пользователя брокера
FILE_PATH = "README.md"                   # Относительный или абсолютный путь к файлу

CUSTOM_HEADERS = {                        # Кастомные свойства/заголовки сообщения (Properties)
    "custom-header-1": "myValue",
    "file-type": "binary",
    "version": 1.0
}
# ==============================================================
```

### Шаг 2. Автоматическая валидация (Проверки безопасности)

При запуске скрипт автоматически выполняет жесткие проверки параметров с помощью встроенного механизма `assert`. Скрипт мгновенно завершит работу с понятной ошибкой, если:
* Переменная окружения `USER_PASSWORD` не задана или пуста.
* Указанный в `FILE_PATH` файл отсутствует по заданному пути или является директорией.
* Параметры подключения (`BROKER_URL`, `QUEUE_NAME`, `USER_NAME`) заполнены некорректно или имеют неверный тип данных.

### Шаг 3. Запуск скрипта

Убедитесь, что ваше виртуальное окружение активировано `(.venv)`. 

Передайте пароль от учетной записи брокера в переменную окружения `USER_PASSWORD` и выполните запуск. В Linux-системах это делается одной строкой, чтобы пароль не сохранялся в истории терминала:

```bash
USER_PASSWORD="ваш_секретный_пароль" python amqp_send.py
```

### Шаг 4. Ожидаемый результат работы

В случае успешного подключения, авторизации и отправки, в терминале отобразится следующий лог:

```text
Подключаемся к (SSL без проверок): amqps://10.3.124.31:61627/TO.KM, пользователем: main
Отправляем файл: README.md...
Файл README.md успешно отправлен по защищенному протоколу AMQP 1.0 (SSL)!
```

После вывода финальной строки скрипт автоматически и корректно закроет сессию, сетевое соединение с брокером Apache Artemis и завершит свой процесс.
